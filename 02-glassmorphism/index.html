关于我

自我描述

我是 ok-lzr，长期在长沙生活与工作。喜欢把零散的想法做成能用的小页面： 一个导航站、一块天气看板、一组自动化脚本。写代码之外， 爱沿着湘江散步，也会在深夜调一调颜色与模糊半径。

我在意

  • 界面的层次与呼吸感，玻璃要“透而不糊”。
  • 可读性优先：再花哨也要保证文字对比度。
  • 零依赖：原生 HTML / CSS / JS 就够用。
  • 移动先行，360px 上同样顺手。
