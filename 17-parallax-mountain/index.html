01 / 关于

住在山与代码之间

白天写页面，晚上看日落。这个主页用纯 HTML、CSS 与原生 JavaScript 做成： 四层远山负责视差，渐变天空负责昼夜，薄雾负责让距离感看起来真实一点。

主题会按长沙时间自动判断——现在是白天就亮，入夜就暗；也可以点右上角自己切。

02 / 作品

山脚下的几个项目

  • 个人导航站

    把常用入口按使用频率排成一座山脊，支持键盘快速跳转与自定义分组。

    • HTML
    • CSS
    • LocalStorage

  • 长沙天气看板

    按小时展示气温与降水概率，背景随天气在晴、阴、雨之间切换。

    • JavaScript
    • Canvas

  • 层叠山景视差

    用四层剪影与雾带做纵深，滚动与鼠标移动共同驱动视差位移。

    • CSS 变量
    • Parallax
    • SVG

  • 代码片段管理器

    本地保存常用代码片段，支持标签检索、一键复制与语法高亮。

    • JavaScript
    • IndexedDB

  • 文件重命名助手

    按规则批量重命名照片与文档，可预览结果再执行，避免误操作。

    • Python
    • CLI

  • 日出主题生成器

    从一张日出照片里提取主色，自动生成一套可直接使用的 CSS 变量主题。
