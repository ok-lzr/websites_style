🎨作品泡泡墙

6 个小项目，按分类筛一筛，点「详情」还能翻开技术说明。

  • 01

    个人导航站

    把每天要开的十几个站点收进一页彩色格子，分组折叠、随手拖拽排序。

    • HTML
    • CSS Grid
    • 原生 JS

    把常用入口按「工作 / 摸鱼 / 学习」分组，排序结果写进 localStorage；列数交给 CSS Grid 自适应，全程零框架、零依赖。

  • 02

    长沙天气看板

    把一周的温度和湿度画成一排彩色泡泡，再顺手给个穿衣提醒。

    • Canvas
    • 本地 JSON
    • 响应式

    图表用 Canvas 手绘，气泡大小对应温差、颜色对应湿度；样例数据放在本地 JSON 里，断网也能演示。

  • 03

    拼色便签墙

    高饱和便签随便贴、随便拖，双击换个颜色，心情也跟着换。

    • CSS 变量
    • Pointer Events
    • 弹性动效

    拖拽用 Pointer Events 实现，鼠标和触屏一套代码；便签位置与配色保存在本地，刷新后原样回来。

  • 04

    像素泡泡消消乐

    点爆连在一起的同色泡泡，连击越高分越猛，最高分留在本机。

    • Canvas
    • 游戏循环
    • 碰撞检测

    自己写的简易物理与邻接搜索，帧率用 requestAnimationFrame 对齐屏幕；手感调了十几版才够「弹」。

  • 05

    字体试衣间

    输入一句话，实时预览各种字号字重搭配，并给一个对比度评分。

    • CSS
    • 无障碍
    • 实时预览

    对比度按 WCAG 的相对亮度公式计算，全部在浏览器里跑完，不传一个字到服务器。

  • 06

    周报生成器

    把零散的碎碎念一键排成整齐周报，支持 Markdown 与纯文本。

    • 模板字符串
    • 剪贴板 API
    • 原生 JS

    模板可以在页面上直接改，改完立刻生效；一键复制到剪贴板，周五下班前省下十分钟。

🙋关于我

一个喜欢把页面调得很吵、但代码写得很安静的人。

我是 ok-lzr，常驻湖南省长沙市。白天写业务代码，晚上折腾配色和小动画，坚信「好看的东西更容易被用起来」。
