01 / 关于我

少即是多，
黑与白就够用。

我是 ok-lzr，一名常驻湖南省长沙市的开发者。喜欢把需求拆到最小， 再用最朴素的技术把它实现出来：语义化结构、克制的样式、能看懂的行为层。

不依赖任何外部库与字体，这个页面本身就是作品之一——只用黑白灰三种语汇， 把排版、留白和线条当成主要的设计工具。

如果你想聊聊网页、动效或者长沙的夜宵路线，下面任意一个出口都能找到我。

02 / 作品

做过的一些东西

  1. 01

    个人导航站

    把自己常用的站点收进一页，分组折叠、暗色跟随系统，打开就是起点。

    • HTML
    • CSS Grid
    • localStorage
  2. 02

    长沙天气看板

    抓取本地天气与空气质量，用纯手绘折线展示一周变化，无第三方图表库。

    • Canvas
    • Fetch
    • 定时任务
  3. 03

    黑白截图工具

    一键把截图处理成灰度并加深对比，方便写文档时保持版面统一。

    • Canvas 滤镜
    • 拖拽上传
  4. 04

    长沙时间墙

    一个只显示时间与星期的极简壁纸页，昼夜自动换肤，可全屏常驻副屏。

    • Date API
    • CSS 变量
  5. 05

    接口模拟器

    用本地 JSON 假数据模拟接口，支持延迟与错误码，方便前端离线联调。

    • Node 原生
    • REST
  6. 06

    记账小账本

    按标签统计月度支出，输出黑白柱状图与月度对比，数据只存在浏览器里。

    • IndexedDB
    • SVG

该分类下暂时没有作品。
