02 / 作品

堆叠中的项目方块

六个自用或给朋友做的小项目，点开卡片可以看更细的说明。

01

个人导航站

自己用的书签首页，按工作 / 学习 / 娱乐分堆成三列等距方块。

支持拖拽排序、本地存储同步，把所有常用站点压缩到一屏，键盘直接搜站点名跳转。

  • 原生 JS
  • LocalStorage
  • 响应式
02

长沙天气看板

把逐小时温湿度画成堆叠柱体，配色跟着天气和昼夜自动换。

数据落在浏览器缓存里做对比，能看到一周内的趋势变化，离线也能翻历史曲线。

  • Canvas
  • 数据可视化
  • 缓存策略
03

颜色阶梯工具

输入一个主色，自动生成 50–900 的色阶并检查文字对比度。

生成结果可直接复制成 CSS 变量片段，方便在项目里统一色板，避免手调偏色。

  • 色彩算法
  • 无障碍
  • 零依赖
04

Markdown 卡片渲染器

把零散笔记渲染成一页立体卡片墙，滚动时逐块浮现。

自己写的轻量解析器，只支持常用语法，换来极小的体积和完全可控的排版样式。

  • 解析器
  • IntersectionObserver
  • 排版
05

桌搭展示页

给朋友的桌面改造记录做的图文页，实测帧率与噪声数据都在页面上。

长页按时间线分段，每段配一个等距示意图，移动端自动收起成单列阅读流。

  • CSS Grid
  • 滚动叙事
  • 图片优化
06

通勤时间统计器

记录每天上下班耗时，按周汇总成方块密度图，看哪天最堵。

数据只存在本地，支持导出 CSV；方块越高代表当天路上花的时间越长。

  • 数据统计
  • SVG 图表
  • 本地优先
